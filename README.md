# ElectroNest

Multi-vendor online electronics store — SE2030 Group Project (2026-Y2-S1-KU-25)

## Stack
Java 21 · Spring Boot 4.1.0 · Spring Data JPA · PostgreSQL · Thymeleaf · Bootstrap 5

## Getting Started
```bash
git clone <repo-url>
cd ElectroNest
chmod +x mvnw
./mvnw spring-boot:run
```

## Branches
Each core module lives on its own `feature/*` branch. See branch list for assignments.
